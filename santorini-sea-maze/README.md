# Midori & the Santorini Sea Maze (`santorini-sea-maze`)

An interactive 3D Cycladic whitewashed coastal maze city built with React 19, TypeScript, Three.js (`@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`), featuring:

- **Whitewashed Santorini & Turquoise-Stepped Architecture**: Granular hand-troweled whitewashed stucco walls, glowing aquamarine-turquoise stepped roads & reflection pools, external whitewashed staircases, azure-blue arched doors & shutters, and white & blue Cycladic domes.
- **Shimmering Aegean Sea on the Side**: Animated vertex-wave ocean along the Western & Southern coastal cliffs with a harbor pier, rotating lighthouse beacon, spinning Cycladic windmill, and bobbing sailboats.
- **Spiky Dracaena Dragon Palms & Cacti in Whitewashed Amphora Urns**: Bulbous ribbed ceramic planters holding spiky Dragon Palms and prickly-pear/columnar cacti with dappled palm shadow gobos.
- **Lime-Green Anime Chibi Explorer ("Midori")**: Layered apple-lime wolf-cut/feathered bob hair with bright chartreuse highlights, sparkling emerald-to-lime anime eyes, diagonal `///` blush marks, cute open `"o"` mouth, oversized green turtleneck sweater, flared black pleated skirt, green socks, V-notched black ankle boots, cel-shaded ink outlines, and smooth procedural animations (`Walk`, `Sprint`, `Jump-Twirl`, and `Wave`).
- **16 Interactive Places**: Explore 16 distinct landmarks across a 9×9 coastal maze grid with BFS pathfinding, click-to-walk, auto-tour, and instant teleportation.
- **5 Dynamic Camera Angles**: `3rd-Person Follow`, `Reference Postcard Vista`, `Vibe Director`, `Sea & Domes Panorama`, and `1st-Person POV`.

## Quick Start

```bash
npm install
npm run dev
```
