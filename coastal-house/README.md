# Sumomalo Coffee — Coastal House & Wandering Ronin (Three.js / R3F)

An interactive 3D coastal diorama built with **Three.js**, **React Three Fiber**, **Drei**, **Postprocessing**, and **GSAP**.

## Features

- **Mediterranean Pastel-Blue Stucco House (`CoastalHouse.tsx`)**:
  - Procedural hand-troweled Mediterranean stucco bump & color textures.
  - Iconic stepped L-shaped parapet roofline with rooftop silver chimney cap.
  - Upper-floor recessed teal window with louvered wooden shutter and warm interior shelves.
  - Ground-floor arched **Sumomalo Coffee** shopfront window with vintage gold transom lettering and a full 3D glowing interior cafe diorama (wooden shelves, espresso tins, counter, pendant lamp).
  - Sloped orange/terracotta barrel-tile canopy awning with cream scalloped mortar trim over an interactive hinged teal 6-pane front door.
  - Vintage iron wall lantern, wooden A-frame chalkboard menu sign, terracotta planters with citrus trees & coastal palms, right-side bracketed hanging cafe sign, side awning & bistro patio, and ocean-facing rear bench.
- **Chibi Wandering Ronin Character (`ChibiRonin.tsx`)**:
  - Sculpted 3D chibi samurai wearing a wide woven bamboo straw hat (*kasa*) with a springy green leaf sprout on top, rosy cheeks, dark bobbed hair, sage-green billowy kimono, dark brown pleated hakama pants, bare feet, and a diagonal lacquered katana scabbard.
  - **Move Around the House**: Walk freely around all 4 sides of the house using **WASD / Arrow keys**, **Click-to-Walk** anywhere on the limestone promenade, the **On-Screen D-Pad**, or toggle **Auto-Stroll** mode.
- **Coastal Environment (`CoastalEnvironment.tsx`)**:
  - Custom GLSL Mediterranean turquoise ocean shader with wave crests and coastal seawall foam, low horizon cumulus cloud banks, and a **Sunny Noon / Golden Sunset** lighting toggle.

## Getting Started

```bash
npm install
npm run dev
```
